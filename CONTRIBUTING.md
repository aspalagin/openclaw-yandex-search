# Участие в разработке

1. Создайте ветку от `main` для одной задачи.
2. Не добавляйте API-ключи, `.env`, результаты поисковых запросов или `dist/`.
3. Выполните `npm run typecheck`, `npm test` и `npm run build`.
4. В pull request укажите изменение, проверку и влияние на конфигурацию плагина.

Плагин не публикуется в npm: не предлагайте изменения, которые требуют такой
публикации без отдельного решения владельца.
