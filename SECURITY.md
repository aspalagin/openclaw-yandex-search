# Безопасность

## Поддерживаемая версия

Исправления безопасности вносятся в ветку `main`.

## Сообщить об уязвимости

Не открывайте публичный issue с API-ключом, поисковыми данными или подробным
эксплойтом. Создайте приватный security advisory через вкладку Security
репозитория либо свяжитесь с владельцем через GitHub, приложив минимальные
безопасные шаги воспроизведения.

## Ключи и сеть

Плагин читает `YC_API_KEY`, `YC_FOLDER_ID` и, для Brave в режиме `multi`,
`BRAVE_SEARCH_API_KEY` из окружения. Не записывайте ключи в репозиторий,
конфигурацию, логи или тестовые данные. Запросы передаются в API Yandex Search
и Brave по HTTPS. Unit-тесты используют моки и не требуют внешних ключей.
