# История изменений

Все заметные изменения проекта фиксируются в этом файле.

## 0.2.0 — 2026-09-24

Переработка под контракт web_search ядра OpenClaw 2026.9.x.

- Ошибки движков больше не теряются: упал один — отдаются результаты второго и пишется `warn` в лог Gateway;
  упали оба — инструмент возвращает `{ error: "provider_error", message }` вместо пустой выдачи;
  нет ни одного ключа — `{ error: "missing_api_key" }`. Каждый поиск оставляет строку `[multi-search] yandex=… brave=… merged=… tookMs=…`.
- Строки результата в формате ядра: `title`, `url`, `snippet`, `published` (YYYY-MM-DD), `siteName`; строки без валидного http(s)-URL отбрасываются.
  Пометка источника (`source`) удалена: ядро её всё равно вырезало.
- Аргументы инструмента читаются в snake_case (`date_after`, `date_before`, `freshness`, `search_lang`, `ui_lang`).
  Brave получает `country`, `search_lang`, `ui_lang`, `freshness` и диапазоны дат; Яндекс — `searchType` по стране, `l10n` по языку
  (поле исправлено с `l10N`) и `period` (сутки / 2 недели / месяц). Диапазон, который периодами не выражается, обслуживает один Brave.
- Сигнал отмены ядра и бюджет `tools.web.search.timeoutSeconds` прокидываются во все запросы; опрос операции Яндекса начинается через 300 мс
  (было 1 с) и повторяется каждые 500 мс, на 4xx прекращается. Одна повторная попытка Brave после HTTP 429.
- Кэш результатов через SDK OpenClaw (`tools.web.search.cacheTtlMinutes`, по умолчанию 15 минут); при отсутствии SDK — встроенная реализация.
  Неполные ответы (один движок упал) не кэшируются.
- Ключи читаются при каждом поиске: `tools.web.search.*`, затем `plugins.entries.openclaw-yandex-search.config.*`, затем окружение
  (`YC_API_KEY` / `YC_API_KEY_FILE`, `YC_FOLDER_ID`, `BRAVE_SEARCH_API_KEY` / `BRAVE_API_KEY`). `credentialPath` указывает на реальный путь конфига.
  В `envVars` провайдеров только `YC_API_KEY`: ядро подставляет первую найденную переменную из списка как credential.
- Убран недокументированный заголовок `X-Sw-Engine`; Brave запрашивается с `text_decorations=false`.
- Синхронный режим Yandex Search API намеренно не используется: по тарифу он примерно в 16 раз дороже отложенного.
- Тесты переписаны: `node:test` с поддельным `fetch` и фикстурами, запуск через tsx без сборки; добавлены живые smoke-скрипты.
- `openclaw` объявлен необязательным peer, чтобы `npm install` не подкладывал в `node_modules` устаревшую копию ядра вместо симлинка.

## 0.1.0 — 2026-07-14

- Добавлены воспроизводимая установка, unit-тесты с моками, шаблоны GitHub и CI.
